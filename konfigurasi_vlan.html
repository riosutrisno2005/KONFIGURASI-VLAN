Konfigurasi VLAN

A. Percobaan VLAN dengan Switch Cisco Catalyst

Langkah-langkah untuk mengkonfigurasi VLAN pada Switch Cisco Catalyst antara lain:

  1. Masuk menu switch dengan mengklik double switch
  2. Memilih sub menu CLI, contoh tampilan seperti pada Gambar 1.
  3. Mengaktifkan Switch, yaitu menekan enter kemudian dilakukan dengan mengetikkan enable

a. Membuat VLAN

Sebagai contoh percobaan membangun virtual LAN seperti pada Gambar 2.

Perintah yang digunakan untuk membuat VLAN yaitu:

Switch>enable
Switch#configure terminal
(untuk masuk ke sub menu konfigurasi)
Switch(config)#vlan 3
(membuat VLAN 3)
Switch(config-vlan)#name KANTOR
(memberi nama VLAN 3 dengan nama KANTOR)
Switch(config-vlan)#exit

Switch(config)#vlan 2
(membuat VLAN 2)
Switch(config-vlan)#name MAHASISWA
(memberi nama VLAN 2 dengan nama MAHASISWA)
Switch(config-vlan)#exit
Switch(config)#

b. Memasukkan Port menjadi Anggota Suatu VLAN

Secara default, semua port dalam switch menjadi anggota VLAN 1. Untuk memasukkan port menjadi anggota suatu VLAN, maka dilakukan konfigurasi masing-masing interface ke spesifik VLAN.

Memasukkan port fastethernet 0/1 menjadi anggota VLAN 3:

Switch(config)#interface fastEthernet 0/1
Switch(config-if)#switchport mode access
Switch(config-if)#switchport access vlan 10
Switch(config-if)#exit

Jika ingin memasukkan beberapa port secara bersama-sama menjadi anggota sebuah VLAN, dapat menggunakan interface range untuk efisiensi konfigurasi.

Memasukkan port Fa0/1 hingga Fa0/10 menjadi anggota VLAN 3:

Switch(config)#interface range fa0/1 - fa0/10
Switch(config-if-range)#switchport mode access
Switch(config-if-range)#switchport access vlan 3

Memasukkan port Fa0/11 hingga Fa0/20 menjadi anggota VLAN 2:

Switch(config)#interface range fa0/11 - fa0/20
Switch(config-if-range)#switchport mode access
Switch(config-if-range)#switchport access vlan 2

c. Melihat Hasil VLAN

Untuk memverifikasi konfigurasi VLAN, dapat menggunakan perintah show vlan atau show vlan brief.

Switch:#show vlan

Menggunakan show vlan brief:

Switch:#show vlan brief

d. Menghapus VLAN

Jika akan menghapus sebuah VLAN, dapat menggunakan perintah "No vlan IdVlan". Sebagai contoh, perintah untuk menghapus VLAN 2:

Switch#configure terminal
Switch(config)#no vlan 2

Jadi saat dilihat dengan show vlan brief, VLAN 2 tidak ada tampilan seperti pada Gambar 8.

2. Percobaan VLAN dengan Switch dan Router Cisco Catalyst

Tujuan dari konfigurasi ini adalah menghubungkan antar VLAN yang berbeda menggunakan router (inter-VLAN routing). Sebagai contoh percobaan membangun Virtual LAN seperti pada gambar 9.

a. Merubah IP di PC dan Tambahkan Gateway

PC A:

# ifconfig eth0 192.168.1.2 netmask 255.255.255.0
# route add default gw 192.168.1.1

PC B:

# ifconfig eth0 192.168.2.2 netmask 255.255.255.0
# route add default gw 192.168.2.1

Melakukan tes koneksi antara PC A dan PC B, catat hasilnya!.

b. Menambahkan Setting di Switch pada Kabel yang Terhubung ke Router (Trunk)

Port yang menghubungkan switch ke router harus dikonfigurasi sebagai trunk agar dapat membawa beberapa VLAN sekaligus.

Switch#conf t
Switch(config)#interface fastEthernet 0/4
Switch(config-if)#switchport mode trunk
Switch(config-if)#exit
Switch(config)#

c. Setting Router untuk Interkoneksi Antar VLAN

Konfigurasi pada satu interface di router:

Continue with configuration dialog? [yes/no]: no
Press RETURN to get started!
Router>enable
Router#conf t
Router(config)#interface fastEthernet 0/0
Router(config-if)#no shutdown
Router(config-if)#exit

Penambahan sub-interface disesuaikan dengan banyaknya VLAN yang akan ditangani. Berhubung pada gambar 9 hanya terdapat 2 VLAN, maka perlu dibuat 2 sub-interface saja.

Router(config)#interface fastEthernet 0/0.10
Router(config-subif)#encapsulation dot1Q 10
Router(config-subif)#ip address 192.168.1.1 255.255.255.0
Router(config-subif)#exit

Router(config)#interface fastEthernet 0/0.11
Router(config-subif)#encapsulation dot1Q 11
Router(config-subif)#ip address 192.168.2.1 255.255.255.0
Router(config-subif)#exit
Router(config)#^Z

d. Cek Konfigurasi

Router# show run
(melihat semua konfigurasi dasar di router)
Router# show ip interface brief
(melihat ip di masing-masing interface)
Router# show ip route
(melihat tabel routing)

Melakukan tes koneksi dari PC A ke PC B dengan perintah ping dan traceroute, catat hasilnya dan bandingkan dengan perintah ping sebelum dilakukan setting pada router.

3. Percobaan VLAN Menggunakan Mikrotik

Satu dari beberapa produk Mikrotik yaitu RB250GS. RB250GS termasuk di dalam switch khusus yang dapat mengimplementasikan VLAN di setiap port-nya sehingga membuat jaringan lebih terorganisasi dengan baik. Pada Gambar 10 bagan jaringan untuk contoh implementasi VLAN yang dapat dilakukan oleh produk router mikrotik dan dipadukan dengan switch mikrotik RB250GS.

Jalur Internet akan masuk ke dalam router mikrotik melalui interface ether1 dan akan didistribusikan kembali ke jaringan lokal melalui interface ether2. Ether2 pada router terdapat 2 VLAN yaitu VLAN2 dan VLAN3. Kedua informasi VLAN ini akan diteruskan ke switch RB250GS dengan menghubungkan ether2 dari router ke ether1-Switch. Pada switch RB250GS segmen network 1 dan network 2 akan didistribusikan ke interface yang berbeda. Semua perangkat yang terhubung di kedua port switch ini harus menggunakan routing terlebih dahulu di router untuk berkomunikasi satu sama lain.

a. Konfigurasi Trunk Link

Trunk link adalah sebuah komunikasi antara Switch dengan Switch atau antara Switch dengan Router, yang membawa informasi beberapa VLAN (VLAN ID) yang berbeda di antara kedua perangkat tersebut.

Pada gambar 11 dan gambar 12 adalah contoh pembuatan trunk interface di router. IP address yang berbeda segmen sudah dapat dipasang pada kedua VLAN interface.

b. RB250GS Config

Langkah selanjutnya adalah melakukan konfigurasi switch manageable RB250GS menggunakan web browser dengan username=admin password=[kosong]. Direkomendasikan langkah awal adalah mengubah IP default pada switch dari 192.168.88.1 menjadi IP yang lain untuk menghindari conflict dengan IP default router. Seperti pada Gambar 13.

c. Konfigurasi VLAN Table

Langkah selanjutnya adalah mendaftarkan VLAN ID yang akan didistribusikan pada switch. Port1-switch akan bertindak sebagai trunk port sehingga Vlan2 dan Vlan3 akan di forward pada port ini. Sedangkan Port2, switch hanya mem forward VLAN 2 dan Port3, Switch hanya mem forward VLAN 3.

Pada switch manageable dikenal adanya ingress filtering dan egress filtering untuk mengatur switch memperlakukan traffic yang datang dan meninggalkan port tersebut.

Pada gambar 15, Port1, switch bertindak sebagai trunk menggunakan policy "add if missing", sedangkan Port2 dan Port3, switch bertindak sebagai access port menggunakan policy "always strip".

Cara kerjanya adalah sebagai berikut:

  1. Traffic yang datang dari Port1, yaitu Switch memiliki VLAN header dan VLAN ID yang diterima adalah VLAN dengan ID 2 dan 3 sesuai VLAN table.
  2. Ketika traffic dari router dengan VLAN ID 2 maka akan diteruskan pada Port2, switch. Pada saat traffic meninggalkan Port2 Switch, VLAN header akan dihilangkan (egress policy "always strip").
  3. Traffic balik dari Port2 Switch menuju router akan dikirim ulang ke Port1 Switch dan ditambahkan VLAN header sesuai default VLAN ID (egress port policy add if missing).
